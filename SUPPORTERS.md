# Aeris UI Supporters

Aeris UI is free and open source. Sponsorship helps create more room for maintenance,
accessibility work, documentation, testing, and the infrastructure behind the project.

[Support Aeris UI through GitHub Sponsors](https://github.com/sponsors/lilbuda)

## Supporters

> No supporters have opted into public recognition yet.

Every sponsor, regardless of amount, may optionally be listed here. Sponsors who contribute
US$20 or more may also choose to appear in the
[supporters section on the Aeris UI website](https://www.aeris-ui.dev/support#supporters).
Sponsorship amounts are never displayed, and anonymous support is always welcome.

To request recognition, email [budimir.dev@gmail.com](mailto:budimir.dev@gmail.com) with your
GitHub username, preferred display name, and where you would like to appear. Recognition can be
changed or removed at any time.
