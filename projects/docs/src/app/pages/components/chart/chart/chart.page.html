Import

Chart uses Chart.js as a required peer dependency. Install it alongside the Aeris Chart module.

Features showcase

Chart.js options provide formatting, legends and tooltip callbacks, including multiline labels and external tooltips. Dataset backgroundColor and borderColor control series colors; Aeris themes the surrounding surface, text, axes and tooltips. Your options take precedence, except that system reduced motion disables animations. Chart.js is required only when importing Chart, not for other Aeris components.

These documentation examples explicitly increase options.devicePixelRatio for smoother canvas edges. Aeris itself uses the screen’s native pixel density by default. Higher resolution uses more canvas memory and rendering work; choose it based on your chart size, update frequency and target devices.

Accessibility

Semantics

  • Each rendered canvas exposes role="img" and uses ariaLabel as its accessible name.
  • ariaDescription provides additional context through an associated hidden description.
  • A text summary of labels and dataset values is associated with the canvas through aria-describedby. Add a visible summary or data table when readers need to compare exact values.
  • Empty charts replace the canvas with a named status message.
  • Charts are visualizations, not input controls. Provide equivalent controls outside the chart for any action or filtering workflow.
  • Canvas tooltips and legends are pointer interactions, not keyboard controls. Do not put essential information only in a tooltip, and provide external native controls for toggling datasets when that action is required.
  • Aeris disables Chart.js animations when the system requests reduced motion, including when the preference changes while the chart is open.

Keyboard support

KeyBehavior
TabMoves to the next native interactive element; charts do not add a keyboard stop.
