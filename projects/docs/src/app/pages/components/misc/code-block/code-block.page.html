Import

Install Shiki only when using CodeBlock, then import the component. Shiki is an optional peer dependency; other Aeris entry points do not require or load it. No icon library is required.

Shiki must be installed when importing CodeBlock, even with [highlight]="false". Disabling highlighting avoids loading it at runtime; bundlers still resolve its lazy imports.

Features

Source text stays selectable and is never executed. Coloring is calculated only when the code or language changes. Shiki grammars and its JavaScript regex engine load lazily, without WebAssembly or unsafe HTML rendering. The copy action needs clipboard permission in a secure context, such as HTTPS or localhost.

Interfaces

Design tokens

Shiki provides paired GitHub-based light and dark syntax colors independent of brand palettes, with stronger light-mode colors for Aeris surfaces. Theme changes select the existing token colors without loading or tokenizing the code again. Override the token-color property for an intentional monochromatic presentation.

Accessibility

  • Code uses native pre and code elements. Syntax highlighting never changes the text or relies on color to communicate meaning.
  • A single source has a named, focusable region. Multiple sources use labeled tabs and a linked tab panel with one tab stop.
  • Copy success and failure are announced politely. Clipboard access can be rejected by the browser; text remains manually selectable.
  • Line numbers are decorative and hidden from assistive technology. Line highlighting is visual emphasis, not a semantic error or selection.
  • Source text stays left-to-right in RTL layouts, while navigation arrows follow the interface direction.
  • Mobile copy actions retain their accessible name when their visible label is hidden. Default mobile blocks expand vertically; horizontal swipes reveal long lines without stopping page scrolling.
  • Reduced motion disables button transitions. CodeBlock does not animate or execute source text.
