Interfaces

Design tokens

--aeris-surfaceButtons and rows menu surface.#fff --aeris-borderButton and popup borders.#deddd7 --aeris-primaryCurrent page and selected row option.#2c694b --aeris-focusVisible keyboard focus ring.#536437

Accessibility

  • Paginator is a native nav landmark with a configurable accessible label.
  • Page buttons are native buttons and the active page uses aria-current="page".
  • The current range is announced through polite live text.
  • The rows-per-page menu uses listbox semantics and closes when focus leaves the control.

Keyboard support

TabMoves through page controls and the rows menu. Enter / SpaceActivates a page button or opens the rows menu trigger. ArrowDownOpens the rows menu from the trigger. EscapeCloses the rows menu.
