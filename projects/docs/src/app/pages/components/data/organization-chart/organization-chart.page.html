Accessibility

  • The chart uses tree and treeitem semantics with a configurable accessible name.
  • Nodes expose selected state only when selection is enabled.
  • Branch nodes expose expanded state and use native buttons for collapse controls.
  • The viewport is horizontally scrollable for wide hierarchies without changing source order.

Keyboard support

TabEnters at the active node, then leaves the chart. Projected interactive controls retain their native tab order. Enter / SpaceSelects or clears the focused node when selection is enabled. ArrowLeftCollapses an expanded branch, or moves to the parent node. Reversed in RTL. ArrowRightExpands a collapsed branch, or moves to its first child. Reversed in RTL. HomeMoves focus to the first rendered node. ArrowUp / ArrowDown Moves to the previous or next visible node without changing selection. Letter Moves to the next visible node whose label starts with that character. EndMoves focus to the last rendered node.
