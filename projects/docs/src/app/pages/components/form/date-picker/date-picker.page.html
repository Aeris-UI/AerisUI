Import

One standalone import provides the complete DatePicker API.

Features showcase

Each example uses the same published component and shows the exact template and TypeScript needed for that feature.

Values are JavaScript Date objects interpreted in local time; locale changes formatting, not the time zone. For a calendar date, use numeric constructor arguments: new Date(2026, 5, 11) means June 11. A string such as new Date('2026-06-11') is parsed as UTC and can display a different local day.

Accessibility

  • The popup trigger exposes combobox state and its relationship to the labelled calendar dialog.
  • The day calendar uses grid, row, and gridcell semantics with one roving tab stop.
  • Selected dates use aria-selected, today uses aria-current="date", and unavailable dates use native disabled behavior.
  • Every date receives a complete locale-formatted accessible name rather than exposing only its day number.
  • Date-time mode keeps the calendar semantics and adds labelled time controls. Desktop users can type values or use the stepper buttons; touch devices show draggable number single-row wheels with spinbutton semantics. Time-only mode focuses the hour control when opened. Tap or click the period button to toggle AM/PM. Wheel gestures commit on release and cancelled gestures keep the previous value. Reduced motion disables the snap transition.
  • Visible labels should use inputId. Otherwise provide ariaLabel or ariaLabelledBy.
  • Use ariaDescribedBy for help and validation messages. Required and invalid state are synchronized with ARIA.
  • Multiple-month layouts collapse on narrow screens and all pointer targets retain clear focus indicators.
  • DatePicker uses native Date values with Reactive Forms and template-driven forms.

Keyboard support

With editable, date and time segments remain in the field. Click empty field space to focus its first segment, or click a specific segment to edit it. Date-time entry wraps between its date and clock groups on narrow screens. Paste a complete value in the displayed locale, or use YYYY-MM-DD, HH:mm (including seconds when shown), or YYYY-MM-DDTHH:mm:ss. These are local values, not UTC timestamps. A time-only Date retains its calendar date; the first complete entry into an empty field uses the current calendar date. Typed nonexistent local clocks during a daylight-saving change are rejected; ambiguous clocks use the earlier occurrence. Hidden seconds are retained.

Arrow Up / Down in editable segments Adjusts the focused part without carrying into another segment. Minute and second steps follow their inputs. On AM/PM, toggles the period. Arrow Left / Right in editable segments Moves between segments in visual order, including RTL. Home / End in editable segments Sets the focused part to its minimum or maximum; AM or PM for the period. Delete / Backspace in editable segments Clears the focused part. Incomplete input remains invalid until completed or fully cleared. A / P or a localized period label Sets AM/PM when its segment is focused. Other numeric segments are unaffected. Alt + Arrow Down in editable segments Opens the calendar or time popup. Escape returns focus to the invoking segment or button. EnterOpens the popup trigger or selects the focused date. SpaceOpens the popup trigger or selects the focused date. Arrow DownOpens the popup from its trigger, or moves focus one week forward in the day grid. Arrow UpMoves focus one week backward. Arrow LeftMoves focus one day backward. Arrow RightMoves focus one day forward. HomeMoves focus to the first day of the current week. EndMoves focus to the last day of the current week. Page UpMoves focus to the previous month. Page DownMoves focus to the next month. Shift + Page UpMoves focus to the previous year. Shift + Page DownMoves focus to the next year. Arrow keys in month or year viewMoves through the month or year options using the visual grid direction. Home / End in month or year viewMoves to the first or last option in the visible period. Arrow Up / Down in popup time controlsIncrease or decrease by the configured step, wrapping at the range boundary. Home / End in popup time controls Select the minimum or maximum value for that control. Enter / Space on the period button Toggle between AM and PM without closing the popup. EscapeCloses a popup calendar and restores focus to its trigger. TabMoves through the popup controls. The popup closes after focus leaves it.
