With alpha, text entry also accepts #RGBA, #RRGGBBAA, rgba(51, 102, 153, 0.5), hsla(210, 50%, 40%, 0.5), space-separated RGB/HSL with slash opacity, and transparent. Opacity can be a number from 0 to 1 or a percentage. HEX stores opacity in 255 steps, so switching to HEX can round it slightly; RGB and HSL retain up to eight decimal places.

Hue, saturation, brightness, and screen sampling retain the current opacity. With alpha enabled, presets without explicit opacity inherit the current slider opacity. Their swatch previews update as you move the slider, and selecting one keeps that opacity. For example, #336699 inherits the slider value, while #33669980 always applies approximately 50% opacity and #336699ff always restores 100% opacity. Typed opaque values and reset() also restore full opacity. The changed.hex value includes alpha when translucent. Screen sampling reads a composited screen pixel, not the original transparent color. Leave alpha disabled for theme seeds and other values that require opaque colors, as the Design Lab does.

Accessibility

  • The trigger exposes aria-haspopup="dialog", expanded state, and a stable relationship to the custom picker panel.
  • For the picker, use a visible label and connect it with inputId. Inline palettes use ariaLabelledBy to reference a visible label. Use ariaDescribedBy for help and validation text.
  • Text entry accepts hex, rgb(), and hsl() strings so color can be edited without pointer interaction.
  • The color plane reports saturation and brightness through slider semantics and supports full keyboard adjustment.
  • Hue and optional opacity use native range inputs. Opacity is announced as a percentage. Format choices and preset colors are native buttons with pressed state.
  • Where supported, screen sampling uses the browser-provided EyeDropper API after an explicit button press. Canceling it does not change the selected color.
  • Do not rely on a color swatch alone when naming presets in surrounding application UI. Use preset objects with a readable label. Inline palettes accept ariaLabel or ariaLabelledBy for the group; the selected preset has pressed state and a visible check mark.
  • Invalid state is visual and semantic through aria-invalid; pair it with text that explains the problem.
  • ColorPicker implements ControlValueAccessor for Reactive Forms and template-driven forms.
  • The panel remains within the viewport at narrow sizes, and its opening animation is removed when reduced motion is requested.

Keyboard support

Inline areas and sliders use the same value model and Angular Forms integration as the popup. Label areas with ariaLabel or ariaLabelledBy. Sliders show a channel label by default; these naming inputs can override its accessible name. Read-only controls can receive focus but do not change; disabled controls cannot receive keyboard focus.

Slider arrows / Shift + arrows Increase or decrease the channel by 1 or 10 units. Left/Down decrease; Right/Up increase. Slider Home / End / Page Up / Page Down Jump to the minimum or maximum, or adjust by 10 units. Pointer input updates value continuously; changed emits on release or a keyboard adjustment. Tab / Shift + TabMoves through the trigger, text input, plane, hue slider, format choices, and presets. Each preset group has one tab stop; disabled presets are skipped. Arrow keys; Home / End (presets) Moves focus between enabled presets without changing the value. Left/Right follow text direction; Up/Down move to the previous/next preset. Home/End focus the first/last enabled preset. Enter or Space selects it. Enter / SpaceOpens the panel from the trigger or activates the focused eyedropper, format, preset, clear, or close button. Arrow Left / Arrow RightDecreases or increases saturation on the color plane. Native arrow behavior adjusts hue or opacity on its slider. Arrow Up / Arrow DownIncreases or decreases brightness on the color plane. Shift + ArrowAdjusts saturation or brightness in ten-percent steps. Home / EndMoves saturation to its minimum or maximum on the color plane, or moves a native slider to its minimum or maximum. Page Up / Page DownAdjusts brightness in ten-percent steps. EscapeCloses the panel and restores focus to its trigger. Backspace / DeleteEdits the focused text input using native browser behavior.
